### 함수 정리
---
#### swapcase()
- 문자열의 대문자는 소문자로, 소문자는 대문자로 서로 바꾸어 주는 문자열 메서드
---
#### 특수문자 출력 방법
- r''
  - 반드시 작은따옴표로
  - raw 를 의미하는 r로, regex 에서 pattern 설정 시 escape 문자를 많이 써야해서 자주 사용
- 특수문자 앞에 \
  - 특수문자: \, ', " 
---
#### .join()
- "구분자".join(리스트)
- 리스트나 튜플 같은 반복 가능한 객체의 요소들을 특정 구분자로 연결하여 하나의 문자열로 만들어 주는 메서드
- join 함수는 문자열 요소들만 연결할 수 있음
