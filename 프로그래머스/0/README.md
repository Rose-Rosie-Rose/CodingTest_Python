#### .join()
- "구분자".join(리스트)
- 리스트나 튜플 같은 반복 가능한 객체의 요소들을 특정 구분자로 연결하여 하나의 문자열로 만들어 주는 메서드
- join 함수는 문자열 요소들만 연결할 수 있음
---
#### Comprehension(컴프리헨션)
- 반복문과 조건문을 결합해 리스트, 딕셔너리, 세트 등의 자료구조를 한 줄로 쉽고 빠르게 생성하는 문법
- for
  - [결과값 for 값 in 리스트]
- for + 필터링 if
  - [결과값 for 값 in 리스트 if 조건]
- for + if/else로 값 결정
  - [참일때 결과값 if 조건 else 거짓일때 결과값 for 값 in 리스트]
  - 이 부분은 쉽게 생각하면 js 삼항연산자와 비슷하지만 순서가 다름
  - JS 조건 ? 참일때 : 거짓일때  / python 참일때 if 조건 else 거짓일때

| 하고 싶은 일     | JavaScript  | Python               |
| ----------- | ----------- | -------------------- |
| 값 변환        | `.map()`    | comprehension        |
| 조건에 맞는 값 추출 | `.filter()` | comprehension + `if` |
| 조건에 따라 값 결정 | `? :`       | `참값 if 조건 else 거짓값`  |
| 객체          | Object      | dict                 |
| 배열          | Array       | list                 |
